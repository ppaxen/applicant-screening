# applicant-screening

A Claude Code skill that screens startup/program applicants stored in a Notion
database and produces an organized first-pass review database for a selection
committee — classifying by industry/business model and summarizing evidence
against a 4-criteria rubric, without making the final pass/fail call itself.

See [SKILL.md](./SKILL.md) for the full skill definition.

## Install

Copy (or symlink) this directory into your Claude Code skills folder, e.g.:

```bash
ln -s "$(pwd)/applicant-screening" ~/.claude/skills/applicant-screening
```
